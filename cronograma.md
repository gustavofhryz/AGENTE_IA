## 📌 Semana 1 (Dias 1 a 7): Fundamentos, Machine Learning e Redes Neurais

**Objetivo:** Construir a base matemática e computacional necessária para IA, finalizando com as bases do Deep Learning.

| Dias | Foco Temático | Tópicos & Atividades Práticas |
| :--- | :--- | :--- |
| **Dia 1–2** | Python para IA, Ambiente & Git | • Sintaxe essencial: funções, listas, dicionários, manipulação de arquivos e POO básica.<br>• Configuração de ambiente: Jupyter Notebooks, Google Colab.<br>• Controle de versão: Git e GitHub (commits, repositórios, branches). |
| **Dia 3** | Dados & Matemática Essencial | • Bibliotecas fundamentais: NumPy (cálculo matricial), Pandas (DataFrames) e Matplotlib/Seaborn (visualização).<br>• Matemática prática: Álgebra linear (vetores/matrizes), probabilidade e estatística descritiva. |
| **Dia 4** | Fundamentos de Machine Learning | • Conceitos teóricos centrais: Aprendizado supervisionado vs. não supervisionado.<br>• Riscos de modelagem: Overfitting, underfitting, divisão treino/validação/teste.<br>• Métricas essenciais: Acurácia, precisão, recall, F1-score, matriz de confusão, MSE, R². |
| **Dia 5** | Scikit-learn na Prática | • Algoritmos clássicos: Regressão linear/logística, Árvores de decisão e Random Forest.<br>• Pipelines de pré-processamento de dados.<br>• **Prática:** Primeiro mini-projeto de ML ponta a ponta. |
| **Dia 6** | Redes Neurais do Zero | • Anatomia do neurônio artificial e camadas (camada de entrada, oculta, saída).<br>• Funções de ativação (ReLU, Sigmoid, Softmax).<br>• Mecânica de treino: Forward pass, funções de perda (loss), gradiente descendente e backpropagation. |
| **Dia 7** | Revisão, Mini-Projeto & Descanso | • **Mini-projeto prático:** Submeter uma previsão com dataset real no Kaggle (ex.: Titanic ou House Prices).<br>• Revisão geral das notas da semana + descanso parcial programado. |

## 📌 Semana 2 (Dias 8 a 14): Deep Learning, Treinamento e Visão Computacional

**Objetivo:** Dominar a mecânica de redes profundas com PyTorch e aplicar modelos de visão computacional em um projeto com transfer learning.

| Dias | Foco Temático | Tópicos & Atividades Práticas |
| :--- | :--- | :--- |
| **Dia 8–9** | Deep Learning com PyTorch | • Manipulação de Tensores no PyTorch (ou TensorFlow/Keras).<br>• Construção de arquiteturas modulares (`torch.nn.Module`).<br>• Ciclo de treinamento (loop de treino, cálculo de loss, backpropagation e otimizadores como Adam e SGD). |
| **Dia 10** | Otimização e Treinamento de Modelos | • Técnicas de regularização: Dropout, L1/L2 weight decay.<br>• Batch Normalization e Learning Rate Scheduling.<br>• Hiperparametrização, Data Augmentation e fundamentos de Transfer Learning. |
| **Dia 11–12** | Visão Computacional (CV) | • Redes Neurais Convolucionais (CNNs): filtros, strides, pooling.<br>• Classificação de imagens e detecção de objetos (YOLO).<br>• Manipulação de imagens e vídeo com OpenCV. |
| **Dia 13** | **Projeto de Portfólio 1** | • **Projeto:** Desenvolver um classificador de imagens utilizando Transfer Learning com modelos pré-treinados (ResNet ou EfficientNet). |
| **Dia 14** | Revisão & Publicação no GitHub | • Estruturar repositório no GitHub: código modular, requisitos (`requirements.txt`), `README.md` detalhado em inglês com imagens/gráficos de performance. |

## 📌 Semana 3 (Dias 15 a 21): IAs Generativas e Engenharia de Prompts

> [!IMPORTANT]
> **A partir de hoje (Dia 15):** Candidate-se diariamente a vagas de IA/Python (LinkedIn, Glassdoor, Gupy, etc.) por 30 a 60 minutos.

**Objetivo:** Compreender a revolução dos Transformers e LLMs, dominar técnicas avançadas de prompt engineering e construir uma aplicação RAG.

| Dias | Foco Temático | Tópicos & Atividades Práticas |
| :--- | :--- | :--- |
| **Dia 15** | NLP Básico & Atenção | • Fundamentos de Processamento de Linguagem Natural: tokenização, vocabulários.<br>• Embeddings semânticos (representação vetorial).<br>• O mecanismo de atenção (*Self-Attention*). |
| **Dia 16–17** | Transformers & LLMs | • Arquitetura do Transformer (*Encoder-Decoder*, *Decoder-only* como GPT/Llama).<br>• Diferença prática entre pré-treinamento e fine-tuning.<br>• Visão geral de modelos de difusão (geração de imagens: Stable Diffusion/Flux). |
| **Dia 18** | Hugging Face Hub & Pipelines | • Uso de modelos abertos no ecossistema Hugging Face (`transformers`, `datasets`).<br>• Execução de pipelines de inferência (classificação de texto, sumarização).<br>• Noções de quantização e fine-tuning leve (PEFT/LoRA). |
| **Dia 19–20** | Engenharia de Prompts Avançada | • Técnicas: Zero-shot, Few-shot prompting, Chain-of-Thought (CoT), ReAct prompting.<br>• Configuração de System Prompts eficientes.<br>• Saídas estruturadas com esquemas JSON e avaliação sistemática de respostas de LLMs. |
| **Dia 21** | **Projeto de Portfólio 2** | • **Projeto:** Construção de um Chatbot com **RAG** (Retrieval-Augmented Generation) para responder perguntas sobre documentos próprios (PDF/Markdown) via API de LLM + Banco Vetorial (ChromaDB / FAISS / Qdrant). |
