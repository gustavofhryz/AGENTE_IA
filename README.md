# AGENTE_IA: Plano de Estudos de 30 Dias em Inteligência Artificial

> Plano de estudos de 30 dias em IA, estruturado em documentos Markdown (cronograma, recursos e detalhamento semanal) com apoio de agentes de IA.

## Sobre o projeto

Este repositório reúne um **plano de estudos de 30 dias em Inteligência Artificial**, criado com o **Claude** (Anthropic) e o **Google Antigravity**.

O objetivo é dar estrutura e consistência a uma rotina intensa de estudos (5 a 10h por dia) na área de IA.

## O que tem no repositório

| Arquivo | Conteúdo |
| --- | --- |
| `Plano de Estudos de 30 Dias Inteligência Artificial` | Plano completo: objetivo, ordem dos tópicos, cronograma e materiais |
| `cronograma.md` | Cronograma dos 30 dias distribuído em 4 semanas |
| `recursos.md` | Cursos, plataformas e referências de estudo |
| `semana-01.md` | Detalhamento da Semana 1 (fundamentos, Machine Learning e redes neurais) |
| `LICENSE` | Licença do projeto |

## O plano de estudos

Os tópicos seguem uma ordem de progressão, do básico ao mais avançado:

1. Base: Python, dados e matemática essencial
2. Machine Learning básico
3. Redes Neurais
4. Deep Learning e treinamento de modelos
5. Visão Computacional
6. IAs Generativas (Transformers e LLMs)
7. Engenharia de Prompts
8. Agentes de IA

| Semana | Dias | Foco |
| --- | --- | --- |
| 1 | 1 a 7 | Fundamentos, Machine Learning e Redes Neurais |
| 2 | 8 a 14 | Deep Learning, treinamento e Visão Computacional |
| 3 | 15 a 21 | IAs Generativas e Engenharia de Prompts |
| 4 | 22 a 30 | Agentes de IA, projeto final e preparação para emprego |

Meta de portfólio ao final do plano: 1 projeto de visão computacional, 1 com RAG e 1 com agentes de IA.

## Plataformas e referências

O plano prioriza conteúdos de plataformas ligadas a grandes empresas: **DIO**, **Google**, **IBM SkillsBuild**, **NVIDIA Deep Learning Institute**, **Microsoft Learn**, **AWS Skill Builder**, **DeepLearning.AI**, **Hugging Face** e **Anthropic**. A lista completa, por semana, está em `recursos.md`.

## Como foi feito

- **Plano de estudos:** gerado com o Claude e salvo como documento editável no Claude Docs.
- **Estruturação dos arquivos:** feita no Google Antigravity, a partir do conteúdo do plano.
- **Formato:** Markdown, para leitura direta no GitHub.

## Como usar

1. Leia o plano completo para entender a ordem dos tópicos.
2. Siga o `cronograma.md` dia a dia.
3. Consulte o `recursos.md` para escolher os cursos de cada semana.
4. Use o `semana-01.md` como modelo de detalhamento; os arquivos das demais semanas seguem o mesmo padrão.
