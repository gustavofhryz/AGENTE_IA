# 🚀 Plano de Estudos de 30 Dias: Inteligência Artificial Aplicada

> **Meta:** Atingir em 30 dias um perfil júnior empregável em **IA Aplicada (IA Generativa, LLMs e Agentes de IA)**, construindo uma base sólida, certificações reconhecidas e 3 projetos práticos de alto impacto no GitHub.

---

## 🎯 Pilares do Objetivo

- **Base Teórica e Prática:** Python fluente, Machine Learning clássico, Redes Neurais e Deep Learning.
- **Visão Computacional:** Noção prática e treinamento/fine-tuning de modelos (CNNs, YOLO, Transfer Learning).
- **IA Generativa e Agentes:** Domínio prático de LLMs, Engenharia de Prompts, RAG (Retrieval-Augmented Generation), frameworks agênticos (LangChain, LangGraph, CrewAI) e autonomia com ferramentas.
- **Portfólio & Certificados:** 3 projetos completos publicados no GitHub com README em inglês e certificações reconhecidas (Microsoft, AWS, NVIDIA, Google, IBM).

---

## ⏰ Modelo de Rotina Diária (8h / dia)

| Bloco | Duração | Foco |
| :--- | :--- | :--- |
| 📖 **Teoria** | 3 horas | Aulas, cursos, leituras conceituais e documentação |
| 💻 **Prática** | 3 horas | Implementação de código, notebooks no Colab/Jupyter e exercícios |
| ✍️ **Revisão** | 1 hora | Anotações, consolidação dos aprendizados no diário de bordo |
